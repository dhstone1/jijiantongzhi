# 一键部署（Docker 镜像包）

把这个目录整个拷到目标机器就能用：**目标机器不需要源码，也不需要装 Node / Python**，只要装好 Docker。

## 包里有什么

| 文件 | 用途 |
|---|---|
| `jijiantongzhi-images.tar` | 两个镜像：`jijiantongzhi-backend:2.1`、`jijiantongzhi-frontend:2.1` |
| `docker-compose.yml` | 只引用镜像，不构建 |
| `env.example` | 部署参数样例，脚本会自动复制成 `.env` |
| `install.sh` / `install.bat` | 一键部署脚本（Linux / Windows） |
| `安装说明.md` | 本文件 |

## Linux

```bash
unzip jijiantongzhi-docker-2.1.zip -d /opt/jijiantongzhi-docker
cd /opt/jijiantongzhi-docker
sudo bash install.sh
```

脚本会依次做三件事：`docker load` 导入镜像 → 生成 `.env`（自动填本机 IP 当图片地址）→ `docker compose up -d`。

访问 `http://<服务器IP>/jijiantongzhi/`，演示手机号 `13900000000`（省级管理员）。

## Windows

装好 Docker Desktop，把包解压到任意目录，双击 `install.bat`。访问 `http://localhost/jijiantongzhi/`。

## 部署参数（`.env`）

```ini
# 对外端口，默认 80；被占用就改成 8080 之类
WEB_PORT=80

# 钉钉客户端拉报表图片用的地址：填本机 IP 或域名，不要带 /jijiantongzhi
PUBLIC_BASE_URL=http://192.168.1.9
```

改完 `.env` 后执行 `docker compose up -d` 生效。

> `PUBLIC_BASE_URL` 很关键：钉钉是在手机上拉图的，填 `127.0.0.1` 或留空都会导致群里的报表图裂掉。
> 部署后也可以进「系统设置 → 图片服务地址」里改，效果一样。

## 数据在哪

- 系统库、演示库、导入的本地库、报表图片都在命名卷 `jijiantongzhi_data` 里，容器内固定挂在 `/app/data`
  （数据源表存的是库文件的绝对路径，所以这个路径不要改）
- 备份：

```bash
docker run --rm -v jijiantongzhi_data:/data -v "$PWD:/backup" alpine \
  tar czf /backup/jijiantongzhi-data.tgz -C /data .
```

- 升级：把新的 `jijiantongzhi-images.tar` 拷过来 `docker load -i` 一遍，再 `docker compose up -d`，数据卷不动

## 从旧版本升上来（数据目录从 /data 换成 /app/data）

旧镜像把数据放在 `/data`，现在固定成 `/app/data`。卷里的文件还在，但系统库 `data_source`
表里存的是**绝对路径**，老记录写的是 `/data/xxx.db`，直接切过来会找不到库。

一次性改一下存量路径（在部署目录里执行）：

```bash
docker compose exec -T backend python -c "
import sqlite3
c = sqlite3.connect('/app/data/system.db')
for i, fp in c.execute(\"select id, file_path from data_source where db_type='sqlite'\").fetchall():
    if fp.startswith('/data/'):
        new = '/app/data/' + fp[len('/data/'):]
        c.execute('update data_source set file_path=? where id=?', (new, i))
        print('fixed', i, fp, '->', new)
c.commit()
"
docker compose restart backend
```

导入库（`backend/data/imports/*.db` → `/app/data/imports/`）同理，改完在「数据文件」页面点一次
「立即扫描」重新导入也可以，影响更小。

## 常用命令

```bash
docker compose ps          # 状态
docker compose logs -f     # 日志
docker compose down        # 停止（数据卷保留）
docker compose up -d       # 启动
```

## 关于子路径

前端按子路径 `/jijiantongzhi/` 构建，所以：

- 访问地址要带 `/jijiantongzhi/`（直接访问根路径会自动 302 跳过去）
- 后端 `APP_BASE_PATH=/jijiantongzhi` 必须跟它一致，否则钉钉里的图片链接会少一层、图会裂
- 想换子路径：改 `docker/Dockerfile.frontend` 的 `VITE_BASE`、`docker/nginx.conf` 里的 location、
  compose 里的 `APP_BASE_PATH` 三处，然后重新打包
